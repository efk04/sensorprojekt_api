### Phase I
#### Basis API
Programmierschnittstelle erstellen
* Messeinstellungen aus Programm übernehmen
* Messung durchführen (Starten und Stoppen)
* Messdaten zurückgeben und Speichern

#### Vorbereitung Echtzeitdarstellung
Auswertung der Messwerte
* geeignete Darstellungsform wählen
* gespeicherte Messwerte darstellen

### Phase II
#### API erweitern
Messeinstellungen vom Nutzer konfigurierbar machen

#### Messwerte in Echtzeit darstellen
* Daten in Echtzeit auslesen
* Daten in Echtzeit aufarbeiten & darstellen
