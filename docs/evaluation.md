# Evaluation & Visualization (`auswertung_visualisierung.py`)

The evaluation tool `auswertung_visualisierung.py` provides offline post-processing, statistical repeatability analysis, timing benchmarks, and multi-file comparison plots without requiring a connected ISX-3 device.

## Supported File Formats

| Format | Extension | Source |
|---|---|---|
| **Python API HDF5** | `.h5` | Generated by `isx3_api` (`measurement_MAIN_*.h5` or `measurement_MUX_*.h5`) |
| **Sciospec GUI HDF5** | `.scio5`, `.h5` | Exported natively by the official Sciospec ISX-3 Windows software |
| **Sciospec ASCII Spectra** | `.spec` | Single or multi-file ASCII exports (supports automatic MUX sensor & sweep repeat grouping) |

## Launching the Evaluation Tool

```bash
python auswertung_visualisierung.py
```

Upon startup, an interactive CLI menu offers three analysis workflows:

1. **Single Measurement Analysis (`[1]`):** Evaluates one `.h5` / `.scio5` file or a group of `.spec` files belonging to a single measurement campaign.
2. **Direct Two-Run Comparison (`[2]`):** Overlays two datasets (e.g., *Hardware Block Sweep `0xB6 Sub 0x03`* vs. *Python Point-List `0xB6 Sub 0x02`*, or *Python API `.h5`* vs. *Sciospec GUI `.spec`*) and computes relative magnitude deviation ($\Delta \vert{}Z\vert{}$ in %), phase error ($\Delta \phi$ in °), and timing speedup factors.
3. **Multi-Series Comparison (`[3]`):** Compares an arbitrary number of runs (e.g., 3 or more sensor trials or parameter variations) in a unified summary table and overlay plot.

## Diagnostic & Statistical Features

- **Equivalent Circuit Estimation ($R / C / L$):** Automatically classifies the measured impedance based on the mean phase angle $\phi_{\mathrm{mean}}$ and estimates resistance ($\Omega$), capacitance ($\text{pF}$, $\text{nF}$, or $\mu\text{F}$), or inductance ($\text{mH}$).
- **Repeatability Statistics ($\pm 1\sigma$):** For multi-spectrum acquisitions (`number_of_spectra > 1`), calculates mean and standard deviation across repeated sweeps and renders shaded $\pm 1\sigma$ error bands.
- **Timing & Speedup Benchmark:** Extracts `measurement_duration_ms`, hardware timestamps (`hw_timestamp`), single-sweep duration (`ms` / `s`), and average acquisition time per frequency point.
- **Dynamic Autoranging Detection:** Detects current-range switching frequencies (`Code 0..6`) and highlights transition points with vertical dashed lines.
- **Automatic MUX Sensor Matching:** Automatically groups `.spec` exports by channel header or matches multi-file `.spec` exports cyclically/blockwise against multi-sensor API `.h5` runs.

## Plot Types & Styling Presets

| Option | Choices | Description |
|---|---|---|
| **Diagram Type** | `bode`, `dashboard`, `nyquist`, `re_im` | Bode plot ($\vert{}Z\vert{}$ & $\phi$), side-by-side Bode + Nyquist dashboard, Nyquist locus, or Real/Imaginary parts over frequency |
| **Style Preset** | `Laboratory (1.8 pt)` vs. `Presentation (3.0 pt)` | Switches between fine line/marker weights for desktop inspection and bold lines/fonts for presentation slides |
| **MUX Layout** | `Per-sensor subplots`, `Separate windows`, `All-in-one` | Controls how multi-sensor MUX comparisons are arranged across subplots or windows |
| **Axis Scaling** | `Logarithmic` vs. `Linear` | Independent log/linear scaling and optional manual min/max limits for frequency, $\vert{}Z\vert{}$, and phase |
